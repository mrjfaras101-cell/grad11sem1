# مختبر البرمجة التفاعلي — الصف الحادي عشر

موقع تعلّم عربي تفاعلي، ثابت، ومهيّأ للنشر مباشرة على **GitHub Pages**. يغطي الدروس الثلاثة الواردة في الكتاب المرفق:

1. مقدمة في لغات البرمجة — الكتاب، ص 10–17.
2. أساسيات لغة البرمجة بايثون — الكتاب، ص 18–45.
3. الجمل الشرطية — الكتاب، ص 46–59.

## المزايا

- واجهة عربية RTL متجاوبة مع الهاتف واللوح والحاسوب.
- خريطة تعلم لكل درس: أسئلة استهلالية، تهيئة، عرض، شرح، تدريب، توسّع، تقويم، ودليل تنفيذ.
- أسئلة اختيار من متعدد وصح/خطأ، أسئلة متعددة الاختيار، تصنيف بالسحب والإفلات، ترتيب أسطر الكود، ومحاكاة نشاط البطاقات الشرطية.
- تقدم الطالب محفوظ محليًا في المتصفح باستخدام `localStorage`، دون قاعدة بيانات أو خادم.
- مساحات لمسودة مشروع «نجوم وأقمار» وروابط Padlet وPython Tutor وdraw.io وPython الرسمي.
- مظهر فاتح/داكن، ونسخة تعمل دون أي إطار عمل أو حزمة تثبيت.

## التشغيل محليًا

لا يحتاج المشروع إلى `npm` أو أي مكتبات. من داخل المجلد:

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

ثم افتح: `http://localhost:4173`

يمكن أيضًا فتح `index.html` مباشرة، لكن تشغيل خادم محلي أفضل لاختبار جميع المتصفحات.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع الملفات: `index.html` و`style.css` و`app.js` و`README.md` و`دليل-التنفيذ.md`.
3. من **Settings → Pages** اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/root` ثم **Save**.
5. بعد لحظات سيظهر رابط الموقع. لا يحتاج هذا الإصدار إلى build أو secrets.

> إذا كان المستودع خاصًا أو كانت سياسة المدرسة تمنع الروابط الخارجية، استخدم نسخة المدرسة من Padlet/Python Tutor وعدّل الروابط في `app.js` أو من داخل واجهة الموقع.

## تخصيص Padlet

من الصفحة الرئيسة ألصق رابط لوحة Padlet الخاصة بالصف واضغط **حفظ الرابط**. يحفظ الرابط في متصفح الجهاز فقط. يقترح الموقع في نهاية كل درس:

- سؤالًا انعكاسيًا قصيرًا.
- مهمة أو واجبًا مرتبطًا بالدرس.
- مشاركة صورة مخطط سير أو مقطع كود مع مراعاة حقوق الملكية الفكرية.

## ملاحظات فنية

- المحتوى في الموقع صيغ تعليميًا من الكتاب المرفق مع المحافظة على المفاهيم والأمثلة والأرقام الواردة فيه؛ لم يُضف إطار نظري خارج أهداف الدروس إلا بقدر التوضيح والتنظيم.
- محرر الكود داخل الموقع للعرض والتوقع والتدريب، وليس مفسر Python كاملًا. لتتبع التنفيذ خطوة بخطوة افتح رابط **Python Tutor** من أدوات الدرس.
- لا يجمع الموقع أسماء الطلاب أو درجاتهم؛ الحالة محلية على الجهاز. إذا أريد جمع الدرجات مركزيًا، يضاف نموذج المدرسة أو Padlet/Google Forms وفق سياسة الخصوصية.
